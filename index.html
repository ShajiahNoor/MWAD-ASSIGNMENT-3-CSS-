CSS: Cascading Style Sheets

Cascading Style Sheets (CSS) is a stylesheet language used to describe the presentation of a document written in HTML or XML, including formats such as SVG, MathML, and XHTML. CSS describes how elements should appear on screens, on paper, and on other media.

CSS is one of the core languages of the open web and is standardized across web browsers. Earlier versions included CSS1 and CSS2.1. Modern CSS is developed through separate modules, each of which can progress and receive updates independently.

As CSS expanded, different parts of its specification began developing at different speeds. It therefore became more practical to publish recommendations for individual modules. The specification continues to evolve, and modules may have their own version numbers, such as CSS Color Module Level 5.
